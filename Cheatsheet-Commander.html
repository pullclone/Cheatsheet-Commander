Pacman

Arch Linux package management. Replace angle-bracket arguments before running commands; review package transactions.

🌀 Synchronizing & Updating

sudo pacman -Syu

Refresh databases and upgrade the full system; review Arch news and transaction prompts

sudo pacman -Syyu

Force database refresh and upgrade; use only when a normal refresh is insufficient

checkupdates

Check available upgrades using a separate database (pacman-contrib)

checkupdates -d

Download pending upgrades without changing the system sync database (pacman-contrib)

Avoid pacman -Sy and -Syuw: both refresh the live database without upgrading installed packages. Complete a full upgrade before installing more packages.

📦 Installing Packages

sudo pacman -S <pkg1> <pkg2>

sudo pacman -S --needed <pkg>

🧹 Removing Packages

⚠️ Remove + dependents (destructive)

sudo pacman -Rdd <pkg>

⚠️ Ignore dependency checks

Parted

Partition editing on GNU/Linux. Commands marked “Parted prompt” run inside Parted; filesystem tools run in the shell.

📂 Inspect Before Editing

Replace /dev/sdX with the verified target disk. Back up data and unmount affected partitions first. Parted writes changes immediately; quit does not undo them.

lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS

Shell: identify the disk and mounted partitions (Linux)

sudo parted /dev/sdX

Shell: open an interactive Parted session on your chosen disk

help

Parted prompt: list available commands

print free

Parted prompt: display partitions and unallocated space

unit MiB

Parted prompt: use explicit binary units

quit

Parted prompt: return to the shell

🧾 Partition Table & Names

mklabel is for a disk you intend to erase, not a routine setup step on an existing disk.

mklabel gpt

Parted prompt: replace the partition table; existing partitions become inaccessible

print

Parted prompt: inspect the current partition table

name 1 data

Parted prompt: set the GPT name of partition 1

select /dev/sdX

Parted prompt: select another disk; inspect it before changing anything

🛠️ Create, Resize & Remove

mkpart data ext4 1MiB 50GiB

Parted prompt, GPT: create a partition named data; does not format it

align-check optimal 1

Parted prompt: check partition 1 alignment

resizepart 1 100%

Parted prompt: move partition 1 end to the end of the disk

rm 1

Parted prompt: delete partition 1 from the table

resizepart changes the partition boundary only. Grow the filesystem afterward; shrink a supported filesystem before shrinking its partition. Not all filesystems support shrinking.

⚙️ Flags & Current Commands

set 1 esp on

Parted prompt: mark a GPT partition as an EFI System Partition

set 1 lvm on

Parted prompt: mark a partition for LVM

help set

Parted prompt: inspect flag syntax and support

Modern Parted has no move, cp, check, mkfs, or resize command. Use filesystem-specific tools for formatting and repair; use resizepart for the partition boundary.

💡 New Data Disk Example

Erases the selected disk. Example requires a disk larger than 50 GiB. This creates one data partition, not a bootable OS installation.

In the shell:

sudo parted /dev/sdX

At the Parted prompt, inspect the disk, then run:

print mklabel gpt mkpart data ext4 1MiB 50GiB align-check optimal 1 print quit

Back in the shell, verify the new partition path before formatting. NVMe partitions use names such as /dev/nvme0n1p1.

lsblk -f sudo mkfs.ext4 /dev/sdX1 sudo mkdir -p /mnt/data sudo mount /dev/sdX1 /mnt/data df -h /mnt/data

💾 Filesystem Tools (Shell)

Show mounted filesystem space

du -sh dir

Show directory disk usage

sudo mkfs.ext4 /dev/sdX1

Create ext4; destroys existing filesystem data

sudo fsck /dev/sdX1

Check/repair a supported, unmounted filesystem; use its specific repair tool when required

NixOS & Nix

🔧 System Lifecycle

🧹 Store & Generation Cleanup

nix store gc --dry-run

Preview unreachable store paths without deleting generations

nix-collect-garbage

Delete unreachable store paths, retaining profile generations

nix-collect-garbage -d

Delete old generations of discovered profiles you can modify, then collect

sudo nix-collect-garbage -d

Delete old generations of discovered profiles as root, including system profiles, then collect

nix store optimise

Deduplicate identical store files

Deleting generations removes rollback options. Review retained profiles before using -d. Store garbage collection is not a backup strategy.

🏠 Home Manager

home-manager switch --flake .#<user>

Apply a standalone Home Manager flake configuration

home-manager generations

List standalone Home Manager generations

home-manager expire-generations "-7 days"

Remove generation roots older than a week; reduces rollback history

When Home Manager is integrated as a NixOS module, apply it with nixos-rebuild instead. Standalone commands require the home-manager tool to be installed.

🔍 Debugging & Inspection

nix log <installable>

Show available build logs

nix path-info -Sh nixpkgs#<pkg>

Show closure size, including dependencies, in readable units

nix why-depends <a> <b>

Explain a store dependency between installables

nix repl

Start the expression evaluator

If a flake output is missing, inspect flake show and the selected host name. NixOS outputs belong at nixosConfigurations.<host>; development shells include a system attribute.
